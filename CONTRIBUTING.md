# Contributing to Site2Chat

Thanks for your interest in contributing to Site2Chat!

Site2Chat turns website content into shareable, retrieval-augmented AI chatbots. Contributions that improve its reliability, usability, security, and documentation are welcome.

## How to Contribute

### 1. Report Bugs

If you find a bug, open a GitHub issue and include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behavior.
- Relevant error messages or logs, with secrets removed.

### 2. Suggest Features

Open an issue describing the proposed feature, the problem it solves, and how it could improve Site2Chat. For significant changes, discuss the approach before starting implementation.

### 3. Submit Code Changes

1. Fork the repository.
2. Create a branch for your changes.
3. Make focused, easy-to-review changes.
4. Run the relevant tests and checks.
5. Commit your changes with a clear message.
6. Open a pull request against the `main` branch and explain what changed and how you tested it.

### 4. Code Quality

- Keep changes focused and consistent with the existing codebase.
- Avoid unrelated refactoring in feature or bug-fix pull requests.
- Add or update tests when appropriate.
- Update documentation when behavior or setup instructions change.
- Never commit API keys, passwords, access tokens, or other secrets.
- Do not include real user data or private credentials in tests or examples.

### 5. Pull Requests

Pull requests should describe the problem being solved, summarize the changes, and list the tests performed. Changes may require review or revisions before merging.

## Questions?

If you are unsure about a proposed change, open an issue to discuss it before investing time in implementation.

Thanks for helping improve Site2Chat!
